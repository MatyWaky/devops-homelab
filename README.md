# Devops Homelab

## About

This repository contains my practical DevOps learning project.

The project is build on a Proxmox VE homelab environment.

## Goals

- Learn Linux server administration.
- Practice infrastructure automation.
- Learn containerization and CI/CD.
- Build and document a realistic server infrastructure.

## Planned infrastructure

| VM | Purpose |
|---|---|
| OPS01 | Infrastructure management and automation |
| APP01 | Application hosting |
| DB01 | Database server |
| MON01 | Monitoring |
